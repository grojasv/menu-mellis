# 🍽️ Menú Mellis

What the twins eat at CIDE today, on the phone, in CA / ES / EN.

**Live:** https://grojasv.github.io/menu-mellis/

Data comes from the school's monthly menu PDF on the [menjador page](https://www.cide.es/espai-migdia-menjadors/), read by Claude (no API key anywhere). See [SPEC.md](SPEC.md) for the plan.

## Structure
- `index.html`, `style.css`, `app.js`: the whole app. Plain HTML/CSS/JS, no build step.
- `data/variants.json`: the published menu: only the general one (since 0.6.0; the diet menus were dropped).
- `data/src/YYYY-MM.json`: the month's general menu as read from the PDF.
- `data/YYYY-MM.json`: generated by `scripts/build-month.mjs`; what the app loads. `data/index.json` lists the months.
- `scripts/`: fetch the PDF, split it into pages, build and validate the data.
- `.claude/commands/update-menu.md`: the `/update-menu` command that does a monthly update with Claude Code.

## Monthly update
Every morning the **Watch CIDE menu** Action checks the school page. When the page links a new menu PDF (it compares the link only) it opens an issue (label `menu-pdf`, assigned to @grojasv). Then open Claude Code in this folder and run `/update-menu`; it closes the issue when done. Needs Node 22+ and [uv](https://docs.astral.sh/uv/).


## Run locally
```bash
python3 -m http.server 8765
```
Then open http://localhost:8765/.
